# 🌿 AURA BOTANICA — Artisanal Fragrance & Clean Botanical Formulations

A luxury, clean botanical fragrance, skincare, and home sanctum brand website built with modern HTML5, Vanilla CSS3, and JavaScript.

---

## ✨ Features

- **Luxury Minimalist Aesthetic:** Glassmorphism, smooth gradients, Cormorant Garamond serif headings, and Plus Jakarta Sans typography.
- **Light & Obsidian Dark Modes:** Seamless toggle between warm Alabaster light mode and deep Obsidian night mode, persisted via `localStorage`.
- **Interactive Formulations Catalog:** Dynamic category filter tabs (*All Rituals*, *Parfums & Mists*, *Botanical Skincare*, *Sanctum & Candles*).
- **Scent & Mood Finder Quiz:** 2-step interactive quiz providing tailored product recommendations based on desired energy and rituals.
- **Quick Ritual View Modal:** Interactive modal with tabbed views for *Scent Notes*, *Ritual Application*, and *Full Formulation Ingredients*.
- **Sliding Shopping Bag Drawer:** Real-time cart drawer with subtotal calculation, quantity adjustment, promo code engine, and a live free-shipping progress bar.
- **Web Audio API Feedback:** Custom synthesized micro-audio chimes providing acoustic feedback on interactions.
- **Pure PowerShell Local Server:** Zero-dependency standalone local HTTP server script (`serve.ps1`) for instant serving on Windows without needing Node.js or Python.

---

## 🚀 Getting Started

### Option 1: Direct in Browser
Double-click `index.html` or open it with any modern web browser:
```bash
# Windows PowerShell
Start-Process .\index.html
```

### Option 2: Run Local HTTP Server
Run the included PowerShell server script:
```powershell
.\serve.ps1
```
The site will automatically open in your default browser at `http://localhost:8080/`.
